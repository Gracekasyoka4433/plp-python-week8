
# Personal Mini-Toolkit

## Project Description

My Personal Mini-Toolkit is a Python program that provides
three useful tools through a simple menu-driven interface.

The tools include:

1. Simple Calculator - Performs addition, subtraction,
   multiplication and division.
2. To-Do List - Allows users to add, view and remove tasks.
3. Number Guessing Game - Challenges users to guess a
   randomly generated number.

## How to Run the Program

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or another Python editor.
4. Run the following command:

   python toolkit.py

5. Follow the instructions displayed in the menu.

## Python Concepts Used

- User input and output
- If, elif and else statements
- While loops and for loops
- Lists
- Functions
- Random numbers
- F-strings
- Exception handling

## Reflection

The hardest part of this project was creating the main menu
and making sure it returned after each tool finished running.
The bug that took the longest to fix was handling invalid
user inputs without crashing the program. I learned how to
use lists to store tasks and update them while the program
was running. I also improved my understanding of loops and
conditional statements. Testing each tool helped me identify
and correct mistakes. If I had one more week, I would add
a digital clock and a feature that saves tasks to a file.
Overall, this project helped me become more confident in Python.
